# KaguraTJA

**KaguraTJA** 是基于 **OpenTaiko** 基础版（原 `TJAPlayer3-Develop-BSQ`，`TJAPlayer3` 的精神继承者）进行修改与改进的非官方衍生版本，并在开发过程中借助了 AI 辅助。

- 基础项目（OpenTaiko）：https://github.com/0auBSQ/OpenTaiko
- OpenTaiko Discord：https://discord.gg/aA8scTvZ6B
- OpenTaiko Discord（日语）：https://discord.gg/CJ4nTkpy7t
- 基础版更新日志（英语）：https://github.com/0auBSQ/OpenTaiko/blob/main/CHANGELOG.md

## 使用前注意事项（重要）

- **KaguraTJA** 是借助 AI 辅助构建的修改版本。您**全权**对您对本软件的使用负责。无论是 **KaguraTJA** 的制作者还是原始 **OpenTaiko** 的创作者，均不对您使用本软件造成的任何问题承担责任。

- 请勿就 **KaguraTJA** 特有的 Bug、设置或修改内容向原始 **OpenTaiko** 团队或官方支持渠道寻求帮助。

- 在向他人寻求帮助前请先自行研究。

- 若您的计算机不能维持稳定 60FPS 帧率，则本软件不能良好运行。

- 基础版 **OpenTaiko** 自 0.6.0 起可通过 OpenTaiko Hub 下载和管理发布版本：https://github.com/OpenTaiko/OpenTaiko-Hub

## 其他注意事项

歌曲、皮肤和其他资源现位于不同的存储库，并且仅提供最小量用于开发与测试目的，您可以在以下存储库获取相关内容：

- OpenTaiko 原声带：https://github.com/OpenTaiko/OpenTaiko-Soundtrack
- OpenTaiko 皮肤（OWM、Simple Style）：https://github.com/OpenTaiko/OpenTaiko-Skins

### 在直播或视频中使用本软件

若您使用的网站有标签功能，建议打上 **KaguraTJA** 与 **OpenTaiko** 等标签以防止混淆，同时也有助于让相关视频归类展示。

本软件不支持违反版权法律的行为，因此请遵守所在国家的版权法律。此外，反对二次发布试图精准再现特定商业游戏的皮肤。

### 编辑源代码/再发布

基础项目 **OpenTaiko** 在 MIT 许可证下开放源代码。在 MIT 许可证条款下，您可以进行编辑或二次发布，但须**自行承担**全部责任。

此外，根据所用库的许可证要求，在编辑或再发布时**请务必**包含 `Licenses` / `License` 文件夹。

请同样遵守其他皮肤或曲目包创作者的许可证和规则。**OpenTaiko** 与 **KaguraTJA** 的许可不适用于此类情况。

### 目标/非目标

**目标**

- 在 **OpenTaiko** 基础版之上改进画面表现、游玩体验与易用性（QoL）功能。

- 增强定制与皮肤制作的潜力，让玩家能更轻松地以自己的风格游玩太鼓。

- 持续进行性能优化、问题修复与体验提升。

**非目标**

- 精准复制其他游戏或商业许可。

## 关于发布 Issue 或 Pull Request 的规则

我们十分感谢您发布 Issue 或 Pull Request。

- **请**遵守适用的版权法律与社区规范。

- **重要**：当您发布 Issue 时，请写明您使用的构建/提交版本与问题的复现步骤。如果是游戏崩溃，请附上日志文件（如 `TJAPlayer3.log` 或 `OpenTaiko.log`）。

- 由于本修改版的部分内容借助 AI 辅助完成，欢迎提供测试与审查反馈。

- 如需 CLang 翻译相关事宜，请提前联系。

### 功能需求

如果您希望添加功能，欢迎提出建议。如果建议合适，可能会被采纳实现。

- **重要**：类似于“请按照（此处插入任意商业游戏名称）重建用户界面与体验”的请求通常会被拒绝。
