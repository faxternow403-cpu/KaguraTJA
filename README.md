# KaguraTJA

**KaguraTJA** is an unofficial modification and improvement build based on the **OpenTaiko** base edition (formerly `TJAPlayer3-Develop-BSQ`, a spiritual successor to `TJAPlayer3`), developed with AI assistance.

- Japanese README: https://github.com/faxternow403-cpu/KaguraTJA/blob/main/README-JA.md
- Chinese README: https://github.com/0auBSQ/OpenTaiko/blob/main/README-ZH.md
- Base Project (OpenTaiko): https://github.com/0auBSQ/OpenTaiko
- OpenTaiko Discord: https://discord.gg/aA8scTvZ6B
- OpenTaiko Japanese Discord: https://discord.gg/CJ4nTkpy7t
- Base Changelogs: https://github.com/0auBSQ/OpenTaiko/blob/main/CHANGELOG.md

- **KaguraTJA** is a modified build created with AI assistance. Using this software is **YOUR RESPONSIBILITY**. Neither the **KaguraTJA** author nor the original **OpenTaiko** creators take responsibility for any problems you get from using this software.
- Please do not contact the original **OpenTaiko** team or official support channels regarding bugs, settings, or changes specific to **KaguraTJA**.
- Please research before asking people.
- If your PC cannot maintain 60fps stably, it will not work well with the software.
- Base **OpenTaiko** releases from 0.6.0 onwards are managed via OpenTaiko Hub: https://github.com/OpenTaiko/OpenTaiko-Hub

## Additional notes

Songs, skins, and different assets are in separate repositories, and only the minimum is provided for development/testing purposes. You can get additional content from the following repositories:

- OpenTaiko Soundtrack: https://github.com/OpenTaiko/OpenTaiko-Soundtrack
- OpenTaiko Skins (OWM, Simple Style): https://github.com/OpenTaiko/OpenTaiko-Skins

### Goals / Non-goals

**GOALS**

- Build upon the **OpenTaiko** base edition with improvements and enhancements for gameplay, rendering, and usability.
- More customization for better skinning potential, making it easier and more accessible to play Taiko in your own style.
- Optimizations, bug fixes, and QOL features.

**NON-GOALS**

- Copying other games or commercial licenses accurately.
